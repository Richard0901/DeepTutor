```
project-governance/
├── README.md                        # 本文件
```

## 证据规则

1. **不倒填**：未完成事项一律如实标注，不事后补写为"已完成"。
2. **可追溯**：每次基线变更、决策锁定、阶段闸门放行均需在对应登记表中追加带日期的记录。
3. **数据隔离**：真实病例、学员数据、知识库原始文档只存在于本地 `data/`（已被 .gitignore 排除），禁止进入 git 历史或外部仓库。
4. **放行双签**：涉及诊断、处置或正式成绩的功能，须"医学负责人 + QA"双签后方可合入主干。
