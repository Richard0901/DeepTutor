# 病例生产指引（呼吸内科专家版 · 一页）

> 目标：把您日常教学的病例变成平台可用的 L1-L4 分级病例。每个病例约 30-60 分钟，双审通过后计入病例库数量。

## 一、您需要做什么

1. 按下方字段表填写一份 **JSON 病例文件**（模板见 `deeptutor/clinical/seed_cases/` 中任一文件，可直接复制修改；模板示例 `scripts/import_clinical_cases.py --emit-template 目录`）；
2. 交教学秘书导入平台（`python scripts/import_clinical_cases.py 病例目录`），进入 **draft** 状态；
3. **两名专家**在平台（或对 JSON 逐项）审核，分别确认医学正确性与分级合理性 → 状态 approved → 发布 published；
4. 发布后病例才能进入课堂训练。

## 二、字段速查

| 字段 | 填什么 | 注意 |
|---|---|---|
| case_code | 编号，如 RESP-L2-011 | L 后数字 = 层级；同一编号不可重复 |
| title / disease | 病例标题 / 主要疾病 | — |
| level | L1-L4 | 按"四维评分"定级（下表） |
| dimensions | 四维评分各 1-5 分 | 病例复杂度/诊断难度/决策复杂度/情境特殊度 |
| knowledge_points | 知识点（code + 名称） | 病例覆盖的核心知识点 1-5 个 |
| content.chief_complaint 等 | 主诉、现病史、既往史、查体 | 文本，同病历书写规范 |
| content.auxiliary_exams | 辅助检查列表 | 每项标 is_key_evidence（是否关键证据） |
| content.diagnosis | 参考诊断（答案） | 学员不可见，仅教师与评估用 |
| content.key_evidence | 关键证据清单 | ≥3 条 |
| content.differential_diagnosis | 鉴别诊断及依据 | ≥1 条，写清"为什么是/不是" |
| content.common_errors | 常见错误 | 每条含 error_type（八类之一）+ 诱发提问；≥2 条 |
| content.training_objectives | 教学目标 | ≥1 条 |
| content.standard_workflow | 参考诊疗路径 | 分步骤 |
| content.scoring_rubric | 评分量表 | 5 个维度 + 权重（合计 100） |
| source.origin | 来源 | **真实病例必须标 approved_desensitized 并完成脱敏与伦理备案**；纯教学编写标 synthetic；既有教学病例标 original |

**八类常见错误类型**（common_errors 的 error_type 只能用这些代码）：症状归因 symptom_attribution、鉴别排除缺失 differential_exclusion、证据整合错误 evidence_integration、决策依据缺失 decision_rationale、逻辑断点 logic_breakpoint、证据缺环 evidence_gap、决策偏差 decision_bias、伦理盲区 ethical_blind_spot。定义见 D2 决策稿。

## 三、L1-L4 四维分级标准（申报书口径）

| 层级 | 特征 | 四维典型分（复杂/诊断/决策/情境） |
|---|---|---|
| L1 | 单一症状识别、典型体征、"三基"训练 | 1-2 / 1-2 / 1-2 / 1 |
| L2 | 多症状交叉、常见鉴别、规范诊疗流程 | 2-3 / 2-3 / 2-3 / 1-2 |
| L3 | 多系统整合、复杂鉴别推理 | 4 / 4 / 3-4 / 2-3 |
| L4 | 军事特殊情境、批量伤员、资源受限决策 | 5 / 4-5 / 5 / 4-5 |

## 四、质量红线（不满足不计数）

- 未完成字段、无审核记录的病例**不计入** 150 个的正式数量；
- 诊断与处置内容须经两名专家确认；分级分歧由医学总负责人仲裁；
- 提示与反馈文本不得直接泄露答案（common_errors 的 trigger_feedback 用提问引导，不写结论）；
- 真实患者信息（姓名、住院号、影像原始文件）一律不得出现在 JSON 中。
