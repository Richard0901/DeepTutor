# D1 决策签字稿：150 个病例的计数口径

> 《DeepTutor二次开发计划-2026-07-24》第十三节第 1 项。**此项决定病例库的工作量估算与验收口径，为 MVP 冲刺前必须锁定事项。**
> 状态：**待签字** ｜ 起草：2026-10-06 ｜ 责任人：医学总负责人

## 决策问题

申报要求 L1-L4 分级病例不少于 150 个（40/40/40/30）。现有约 200 余个病例（呼吸内科教学积累）如何计数？

## 方案对比

| 维度 | 方案 A：现有病例重分类为主 | 方案 B：全部新增 |
|---|---|---|
| 工作量 | 低：按四维标准重新分级 + 结构化补全（模板字段约 20 项） | 高：600-900 临床专家工时从零投入 |
| 质量可控性 | 高：既有病例经过多轮教学检验 | 中：新病例需全新双审 |
| 验收风险 | 需在立项材料中明确"重用+新增"口径，避免评审质疑凑数 | 口径干净，但 2027-11 前完成 150 个新增压力极大 |
| 对 MVP 的贡献 | 快：2-4 周可产出首批 20-30 个结构化病例 | 慢：阻塞 G2 闭环验证 |

**建议：采用方案 A，并附加质量闸门**——

1. 现有病例经"结构化改造 + 四维评分 + 双审"后方可计入数量（无 schema、无审核记录的不计数，符合计划"数量服从质量"原则）；
2. 重分类病例在 `source.origin=original` 下登记，并保留原始出处；
3. 缺口部分（现有病例中不足 L4 军事情境等类别的）以新增补齐，新增部分标记 `origin=synthetic`（教学场景合成）或 `origin=approved_desensitized`（真实病例脱敏，需伦理备案先行）；
4. 对外表述统一为："以 200 余个既有教学病例为基础结构化重构，按 L1-L4 标准分级入库，其中新增 XX 个"。
